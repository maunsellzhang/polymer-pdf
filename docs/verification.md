# 验证说明

## 自动检查

```sh
npm ci
npm run format:check
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

核心测试验证多页与原始尺寸保留、排序、PDF/图片混合导出、无效输入、文件名兼容性、大小限制，以及读取途中移除/清空不复活文件、不泄漏图片 URL。

浏览器检查操作真实按钮与文件选择器，覆盖多页预览、所有缩放选项、快速切换、顺序调整、下载后解析页面、错误文件阻止导出、移除恢复、清空重导入与移动端溢出检查。默认启动独立生产预览服务；`SMOKE_URL` 可指定部署后的网址。

## 发布前人工检查

- PDF、PNG、JPG 拖放导入；图片方向、比例与预览内容正确。
- 混合导出后使用独立阅读器确认页数、顺序、页面尺寸和可读性。
- 中文与长文件名可读；桌面、手机宽度下按钮不被遮挡，滚动和键盘焦点可用。
- EXE 在不连接网络时可导入、预览、合并；确认保存、取消、重复保存与退出提示。
- 对 Release 下载文件比对 SHA-256；确认 Pages 子路径下 Worker、字体及 WASM 可加载。
- 不忽略文件读取错误；出现错误时验证提示和恢复路径。

这些检查覆盖当前支持的常见流程，并不等于对所有 PDF 变体或设备的兼容保证。交互表单、签名及加密文件的支持边界见 README。
